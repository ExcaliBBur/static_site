# Вывод

## Рекомендуемый стек

Предметная область — вычислительные эксперименты по машинному обучению и
численным методам: результаты — таблицы метрик, кривые обучения, формулы,
фрагменты кода, ссылки на литературу.

| Слой | Рекомендация | Обоснование (раздел отчёта) |
|---|---|---|
| Генератор | **Sphinx + MyST-Parser** (тема Furo), `sphinxcontrib-bibtex`, `sphinx-design` | нумерация и ссылки на формулы, рисунки, таблицы и листинги при сборке; библиография «автор, год»; ноль внешних запросов (P2, § 4) |
| Альтернатива для документации проекта | MkDocs + Material | в 2 раза быстрее сборка, лучше поиск и интерфейс; научные элементы требуют ручной работы (P2, § 4) |
| Графики | Matplotlib (PNG) по умолчанию; Plotly — только там, где интерактивность нужна для анализа | Plotly.js — 65 % веса страницы, 4,7 МиБ (P2, § 3.2) |
| Формулы | MathJax 3, **локальная копия** | работа без CDN проверена автоматически (P2, § 3.4) |
| Конвейер данных | скрипт `prepare.py` перед сборкой: данные → расчёт → графики/таблицы → метка версии | числа на странице не расходятся с данными; хеш данных виден читателю (T5, § 2) |
| CI/CD | GitHub Actions: `upload-pages-artifact` + `deploy-pages`, actions по SHA, healthcheck после деплоя | без долгоживущих токенов с правом записи в репозиторий |
| Хостинг | GitHub Pages — основной; Helios — зеркало в отечественной инфраструктуре | постоянство URL, HTTPS, свой домен недоступны на Helios (T5, § 8) |
| Публикация | Git-тег → GitHub Release → Zenodo (DOI), `CITATION.cff`, ORCID, мета-теги Highwire/DC/OG, раздельные лицензии CC BY 4.0 / MIT / CC0 | FAIR и цитируемость обеспечивает инфраструктура, а не генератор (T5, § 6, 10) |

## Условия, при которых рекомендация меняется

| Условие | Что выбрать вместо |
|---|---|
| Результаты — в основном Jupyter-ноутбуки, их нужно исполнять при сборке | Sphinx + **MyST-NB** (или Jupyter Book) — кэш исполнения ноутбуков |
| Нужны PDF/печатная версия того же текста | Sphinx (LaTeX-билдер) или Quarto; MkDocs PDF не делает |
| Нужна «публикация из коробки»: блок цитирования, ORCID, Highwire, DOI в метаданных | **Quarto** — если допустим не-Python инструмент в CI |
| Сайт — документация кода с частыми правками, важны поиск и навигация, формул мало | MkDocs + Material (+ `mike` для версий) |
| Сайт — блог/лента заметок об экспериментах | Pelican |
| Команда пишет только Markdown и не готова к синтаксису ролей и директив MyST | MkDocs + Material; научные элементы — ручной HTML и плагины |
| Нет доступа к GitHub, нужна только отечественная инфраструктура | та же сборка в GitVerse/SourceCraft CI; хостинг — объектное хранилище с собственным доменом, а не Helios |
| Результат должен цитироваться годами | обязательно Zenodo (DOI) + собственный домен; учебный хостинг не подходит |
| Нужна работа без JavaScript (печать, строгие требования доступности) | Sphinx (номера формул есть в HTML); MathJax заменить на серверный рендеринг формул в SVG |
